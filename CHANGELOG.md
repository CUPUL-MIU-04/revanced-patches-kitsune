# Changelog - ReVanced Patches Kitsune

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere al [Versionado Semántico](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Soporte inicial para Kitsune v4.5.4
- Nuevo parche de compatibilidad para ROMs personalizadas
- Integración con ReVanced Patcher v19.0.0

### Changed
- Renombrado de paquetes de `app.revanced` a `app.kitsune`
- Mejorado el sistema de compilación para generar archivos .rvpk

### Fixed
- Corrección de compatibilidad con dispositivos ARMv7
- Solucionado problema con permisos en Android 14+

## [4.5.3] - 2024-03-15
### Added
- Primer lanzamiento público de Kitsune Patches
- Parches básicos para:
  - Eliminación de anuncios
  - Compatibilidad con microG
  - Temas personalizados

### Changed
- Configuración inicial del proyecto
- Adaptación de parches originales para Kitsune
