- **Enhanced compatibility** with latest app versions
- **Additional patches** not available in main ReVanced
- **Regular updates** with new features and fixes
- **Custom branding** for Kitsune projects

## 🛠️ Installation

1. Download the latest `.rvpk` file from [Releases](https://github.com/CUPUL-MIU-04/revanced-patches-kitsune/releases)
2. Use with [ReVanced CLI](https://github.com/revanced/revanced-cli):
   ```bash
   revanced patch \
     --patch-bundle patches-4.5.3.rvpk \
     --out patched.apk
