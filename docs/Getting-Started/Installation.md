# Instalación de ReVanced Patches Kitsune

## Requisitos previos
- Java JDK 17+
- Android SDK
- Git

## Métodos de instalación

### Opción 1: Usar builds precompilados
1. Descarga el último `.rvpk` de [Releases](https://github.com/CUPUL-MIU-04/revanced-patches-kitsune/releases)
2. Usa con ReVanced CLI:
   ```bash
   revanced patch --patch-bundle patches-X.X.X.rvpk --out patched.apk
